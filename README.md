# Trading Assistant G

React + TypeScript + Vite trading dashboard.

## Source
The complete application source is stored in `trading-assistant-g-source.zip.b64`. GitHub Actions decodes and extracts it during deployment.

## Local run
Decode the source archive, extract it, then run `npm install` and `npm run dev`.

## Deployment
GitHub Actions builds the Vite app and publishes it to GitHub Pages on pushes to `main`.

> Market data in this project is informational/demo data where live feeds are not available. It does not place broker trades.
